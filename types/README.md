# @cloudops-tools/types

Shared TypeScript contracts for CloudOps Tools.

## Install

```bash
npm install @cloudops-tools/types
```

## Import paths

- `@cloudops-tools/types`
- `@cloudops-tools/types/aws`
- `@cloudops-tools/types/inventory`
- `@cloudops-tools/types/progress`
- `@cloudops-tools/types/query`
- `@cloudops-tools/types/config`

## Notes

- This package is the canonical source for shared SDK/client contracts.
- `@cloudops-tools/sdk/types` remains available as a compatibility alias.
