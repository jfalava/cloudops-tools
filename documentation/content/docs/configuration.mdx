# Configuration

Use `cloudops-tools config` to store persistent defaults such as region, mode, format, and service
filters.

## Command Summary

```bash
cloudops-tools config [subcommand]
```

Available subcommands:

- `set <key> <value>`
- `get [key]`
- `unset <key>`
- `path`

## Supported Keys

| Key               | Type     | Example Value    |
| ----------------- | -------- | ---------------- |
| `defaultRegion`   | string   | `eu-west-1`      |
| `defaultAccount`  | string   | `production`     |
| `defaultFormat`   | string   | `xlsx`           |
| `defaultMode`     | string   | `security`       |
| `defaultServices` | string[] | `EC2,RDS,Lambda` |
| `skipGlobal`      | boolean  | `true`           |
| `onlyGlobal`      | boolean  | `false`          |

## Common Operations

### Set Values

```bash
cloudops-tools config set defaultRegion eu-west-1
cloudops-tools config set defaultFormat xlsx
cloudops-tools config set defaultMode security
cloudops-tools config set defaultServices EC2,RDS,Lambda
cloudops-tools config set skipGlobal true
```

### Read Values

```bash
cloudops-tools config get
cloudops-tools config get defaultRegion
```

### Remove Values

```bash
cloudops-tools config unset defaultServices
```

### Show Config File Path

```bash
cloudops-tools config path
```
