# Commands Overview

This page is the command reference for CloudOps Tools.

## Entrypoint

`cloudops-tools` is the CLI entrypoint.

- Run inventory scans with root options
- Use subcommands for advanced workflows

```bash
cloudops-tools [options]
```

## Subcommands

| Command                                   | Description                                                |
| ----------------------------------------- | ---------------------------------------------------------- |
| [`init`](/docs/cli/commands/init)         | Generate cross-region inventory scan with advanced options |
| [`describe`](/docs/cli/commands/describe) | Deeply describe a specific AWS resource                    |
| [`query`](/docs/cli/commands/query)       | Query historical inventory data from local SQLite database |
| [`config`](/docs/cli/commands/config)     | Manage persistent configuration                            |

## Root Scan Options

These options control the default root scan behavior:

| Option            | Alias | Description                                                                           | Default       |
| ----------------- | ----- | ------------------------------------------------------------------------------------- | ------------- |
| `--account`       | `-a`  | AWS account or profile name                                                           | Auto-detected |
| `--region`        | `-r`  | AWS region(s), comma-separated                                                        | `us-east-1`   |
| `--export-format` | `-f`  | Export format (`csv`, `xlsx`, `json`, `both`, `all`)                                  | `csv`         |
| `--services`      | `-s`  | Comma-separated list of services to scan (`all` supported)                            | All services  |
| `--describe`      |       | Describe all resources of a type                                                      | -             |
| `--no-cache`      |       | Disable caching for describe operations                                               | `false`       |
| `--use-letme`     |       | Use `letme` and `--account` profile for MFA credential obtain (requires `setup-totp`) | `false`       |
| `--skip-global`   |       | Skip global services (S3, IAM, CloudFront, Route53, etc.)                             | `false`       |
| `--only-global`   |       | Scan only global services                                                             | `false`       |
| `--debug`         |       | Show raw error output with stack traces                                               | `false`       |
| `--help-examples` |       | Print CLI examples and exit                                                           | `false`       |

For `--use-letme` setup and troubleshooting workflow, see the
[`use-letme` guide](/docs/cli/commands/use-letme).

## Framework Global Flags

These are provided by `@effect/cli` and appear in help output:

| Option          | Description                                                          |
| --------------- | -------------------------------------------------------------------- |
| `--help`, `-h`  | Show command help                                                    |
| `--version`     | Show application version                                             |
| `--wizard`      | Start wizard mode for command input                                  |
| `--completions` | Generate shell completion script (`sh`, `bash`, `fish`, `zsh`)       |
| `--log-level`   | Set runtime logging threshold (`all`, `trace`, `debug`, `info`, ...) |

## Quick Examples

```bash
# Show help
cloudops-tools --help

# Show examples
cloudops-tools --help-examples

# Show version
cloudops-tools --version

# Basic inventory for us-east-1
cloudops-tools --region us-east-1

# Inventory for multiple regions
cloudops-tools --region us-east-1,eu-west-1

# Scan specific services only
cloudops-tools --services EC2,RDS,S3 --region us-east-1

# Export to Excel format
cloudops-tools --export-format xlsx

# Describe all RDS instances in a region
cloudops-tools --describe rds --region eu-south-2

# Use `letme` with MFA profile from --account
cloudops-tools --use-letme --account engineering-prod --region us-east-1
```

## Behavior Notes

- `--help-examples` prints curated examples and exits.
- `--version` prints the installed CLI version and exits.
- `--wizard` is provided by `@effect/cli`; it helps with command input but does not bypass AWS
  credential requirements.
