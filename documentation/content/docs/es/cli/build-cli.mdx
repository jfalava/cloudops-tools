# Construir CLI binario

Utilice esta guía si desea crear archivos binarios usted mismo en lugar de instalarlos desde npm.

## Requisitos previos

- [Bollo](https://bun.sh) 1.3.8+
  -Git

## Clonar e instalar

```bash
git clone https://github.com/jfalava/cloudops-tools-draft.git
cd cloudops-tools-draft
bun install
```

## Comandos de compilación

Ejecutar desde la raíz del repositorio.

### Compilación nativa para el objetivo de host actual

```bash
bun run cli:build:linux
bun run cli:build:windows
bun run cli:build:macos
```

### Construye todos los objetivos configurados

```bash
bun run cli:build:all
```

## Versión de compilación

Puede inyectar una versión de compilación personalizada:

```bash
BUILD_VERSION=v0.1.1 bun run cli:build:linux
```

Si no se proporcionan, los scripts recurren a `0.5`.

## Artefactos de salida

Los artefactos se escriben en `cli/dist/`.

Ejemplos:

- `cloudops-tools-linux-x64.zip` -`cloudops-tools-windows-x64.zip` -`cloudops-tools-macos-arm.zip`

## Ejecutar CLI local sin empaquetado

Para el desarrollo, ejecute directamente desde la fuente:

```bash
bun run cli -- --help
```
