# consulta

Consulta los datos históricos del inventario almacenados en la base de datos SQLite local sin volver a escanear AWS.

## Uso

```bash
cloudops-tools query [options]
```

## Descripción

El comando `query` le permite analizar ejecuciones de inventario anteriores almacenadas localmente en `~/.config/cloudops-tools/inventory.db`. Esto permite el análisis de tendencias, la detección de cambios y la generación de informes históricos sin realizar llamadas a la API de AWS.

## Opciones| Opción | Alias ​​| Descripción | Predeterminado |

| ---------------- | ----- | ------------------------------------------------ | ----------- |
| `--account` | `-a` | Cuenta de AWS para consultar | `default` |
| `--type` | `-t` | Filtrar por tipo de recurso (por ejemplo, EC2, RDS, Lambda) | Todos los tipos |
| `--region` | `-r` | Filtrar por región de AWS | Todas las regiones |
| `--days` | `-d` | Consultar recursos de los últimos N días | Todo el tiempo |
| `--from` | | Consulta desde fecha (formato ISO: AAAA-MM-DD) | - |
| `--to` | | Consulta hasta la fecha (formato ISO: AAAA-MM-DD) | - |
| `--limit` | `-l` | Limitar el número de ejecuciones para mostrar | `10` |
| `--runs` | | Listar todas las ejecuciones de inventario | `false` |
| `--changes` | `-c` | Mostrar cambios desde la última ejecución | `false` |
| `--changes-days` | | Días para comparar cambios | `7` |

## Subcomandos

### Ejecuciones de listaEnumere todas las ejecuciones de inventario anteriores:

```bash
cloudops-tools query --runs
```

El resultado muestra el ID de ejecución, la marca de tiempo, el modo y el recuento de recursos.

### Consultar recursos

Consultar recursos históricos con filtros:

```bash
# All EC2 instances from last 7 days
cloudops-tools query --type EC2 --days 7

# All resources in us-east-1
cloudops-tools query --region us-east-1

# RDS instances from specific date range
cloudops-tools query --type RDS --from 2024-01-01 --to 2024-01-31

# Limit to 5 most recent runs
cloudops-tools query --limit 5
```

### Detectar cambios

Compare las dos ejecuciones más recientes para detectar cambios en la infraestructura:

```bash
# Show changes from last 7 days
cloudops-tools query --changes

# Compare runs from last 30 days
cloudops-tools query --changes --changes-days 30
```

Tipos de cambio mostrados:

- **Agregado**: Nuevos recursos que no estaban en la ejecución anterior
- **Eliminado**: Recursos eliminados desde la ejecución anterior
- **Modificado**: Recursos con estado cambiado (por ejemplo, instancia detenida)

## Ejemplos

```bash
# List last 20 inventory runs
cloudops-tools query --runs --limit 20

# Find all Lambda functions from last 30 days
cloudops-tools query --type Lambda --days 30

# Check what changed in production account
cloudops-tools query --account 123456789012 --changes

# Query specific region and date range
cloudops-tools query --region eu-west-1 --from 2024-01-01 --to 2024-01-15

# Find all RDS and EC2 resources
cloudops-tools query --type RDS
cloudops-tools query --type EC2
```

## Salida

### Ejecuta la salida

```
ID      Timestamp    Run At                 Mode        Resources
----------------------------------------------------------------------
1       20240215     2024-02-15T10:30:00Z   basic       245
2       20240214     2024-02-14T09:15:00Z   security    245
```

### Salida de recursos

```
Type              Name                                      Region            State
------------------------------------------------------------------------------------------
EC2               instance-1                                us-east-1         running
RDS               db-1                                      us-east-1         available
```

### Cambia la salida

```
Changes detected (7 day(s)):

Added (3):
  + EC2/i-new-instance (us-east-1)
  + RDS/new-db (us-west-2)

Removed (1):
  - EC2/i-old-instance (us-east-1)

Modified (2):
  ~ EC2/i-stopped (us-east-1): running -> stopped
```

## Notas

- La base de datos SQLite se completa automáticamente cuando se ejecuta `cloudops-tools init` o una raíz
  escaneo de comando
  con opciones de escaneo (por ejemplo `cloudops-tools --region us-east-1`)
- Ubicación de la base de datos: `~/.config/cloudops-tools/inventory.db`
- Las operaciones de consulta son instantáneas y no requieren credenciales de AWS
- Los cambios se detectan comparando las dos ejecuciones más recientes dentro del período de tiempo especificado

### Parámetro de cuenta

**Importante:** El indicador `--account` tiene como valor predeterminado `default`. Debe especificar el mismo ID de cuenta utilizado durante `init` para consultar sus datos:

```bash
# First, run init (uses auto-detected account ID)
cloudops-tools init --region eu-central-1
# Account ID: 123456789012

# Query requires the same account ID
cloudops-tools query --runs --account 123456789012

# Without --account, defaults to "default" (no data found)
cloudops-tools query --runs
# Output: No inventory runs found
```

Para encontrar su ID de cuenta:

```bash
# Check what accounts have data
sqlite3 ~/.config/cloudops-tools/inventory.db "SELECT DISTINCT account_id FROM inventory_runs;"
```
