# `config`

Gestiona las opciones de configuración persistente de CloudOps Tools.

## Uso

```bash
cloudops-tools config [--write-defaults] [subcomando] [opciones]
```

## Opciones principales

| Opción             | Descripción                                                                                           |
| ------------------ | ----------------------------------------------------------------------------------------------------- |
| `--write-defaults` | Crea o completa `config.json` con valores por defecto razonables (mantiene los valores que ya tenías) |

## Subcomandos

| Subcomando | Descripción                                  |
| ---------- | -------------------------------------------- |
| `set`      | Establece un valor de configuración          |
| `get`      | Muestra uno o varios valores                 |
| `unset`    | Elimina un valor de configuración            |
| `path`     | Muestra la ruta del archivo de configuración |

## Claves de configuración disponibles

| Clave             | Tipo     | Descripción                                                               |
| ----------------- | -------- | ------------------------------------------------------------------------- |
| `defaultRegion`   | string   | Región AWS por defecto para los escaneos                                  |
| `defaultAccount`  | string   | Cuenta o perfil AWS por defecto                                           |
| `defaultFormat`   | string   | Formato de exportación por defecto (`csv`, `xlsx`, `json`, `both`, `all`) |
| `defaultMode`     | string   | Modo de escaneo por defecto (`basic`, `detailed`, `security`, `cost`)     |
| `defaultServices` | string[] | Servicios que se escanean por defecto                                     |
| `showBanner`      | boolean  | Muestra el banner ASCII al iniciar en terminales interactivos             |
| `skipGlobal`      | boolean  | Omitir servicios globales por defecto                                     |
| `onlyGlobal`      | boolean  | Escanear solo servicios globales por defecto                              |

---

## `config --write-defaults`

Crea un archivo de configuración base con valores sensatos.

Este comando:

- crea `~/.config/cloudops-tools/config.json` si no existe
- escribe un conjunto básico de valores por defecto
- conserva los valores que ya tenías (completa solo lo que falta)

### Uso

```bash
cloudops-tools config --write-defaults
```

### Valores que se escriben por defecto

| Clave           | Valor       |
| --------------- | ----------- |
| `defaultRegion` | `us-east-1` |
| `defaultFormat` | `csv`       |
| `defaultMode`   | `basic`     |
| `showBanner`    | `true`      |
| `skipGlobal`    | `false`     |
| `onlyGlobal`    | `false`     |

### Ejemplo

```bash
cloudops-tools config --write-defaults
# Salida: Escribí la configuración base en /Users/tuusuario/.config/cloudops-tools/config.json
```

## config set

Establece un valor de configuración.

### Uso

```bash
cloudops-tools config set <clave> <valor>
```

### Ejemplos

```bash
# Cambiar la región por defecto
cloudops-tools config set defaultRegion eu-west-1

# Cambiar el formato de exportación
cloudops-tools config set defaultFormat xlsx

# Cambiar el modo de escaneo
cloudops-tools config set defaultMode security

# Establecer servicios por defecto (separados por coma)
cloudops-tools config set defaultServices EC2,RDS,Lambda

# Activar omitir servicios globales por defecto
cloudops-tools config set skipGlobal true

# Elegir cuenta/perfil por defecto
cloudops-tools config set defaultAccount produccion

# Desactivar el banner de inicio (solo en terminales interactivos)
cloudops-tools config set showBanner false
```

---

## config get

Muestra uno o todos los valores de configuración.

### Uso

```bash
# Ver toda la configuración
cloudops-tools config get

# Ver solo una clave
cloudops-tools config get <clave>
```

### Ejemplos

```bash
cloudops-tools config get
cloudops-tools config get defaultRegion
cloudops-tools config get defaultFormat
```

---

## config unset

Elimina un valor de configuración.

### Uso

```bash
cloudops-tools config unset <clave>
```

### Ejemplos

```bash
cloudops-tools config unset defaultRegion
cloudops-tools config unset defaultServices
```

---

## config path

Te muestra dónde está guardado el archivo de configuración.

### Uso

```bash
cloudops-tools config path
```

### Ejemplo

```bash
cloudops-tools config path
# Salida: /Users/tuusuario/.config/cloudops-tools/config.json
```

## Archivo de configuración

Todo se guarda en formato JSON. Ejemplo de cómo queda:

```json
{
  "defaultRegion": "eu-west-1",
  "defaultFormat": "xlsx",
  "defaultMode": "security",
  "defaultServices": ["EC2", "RDS", "Lambda", "S3"],
  "showBanner": true,
  "skipGlobal": false,
  "onlyGlobal": false
}
```

## Banner de inicio

La CLI puede mostrar un banner ASCII (`cli/text-art.txt`) como detalle visual al arrancar.

- Solo se muestra en terminales interactivos (TTY).
- Se oculta automáticamente en usos no interactivos o con pipes/redirecciones.
- Puedes desactivarlo de forma persistente con configuración:

```bash
cloudops-tools config set showBanner false
```

- Puedes desactivarlo solo para una ejecución con una variable de entorno:

```bash
CLOUDOPS_NO_BANNER=1 cloudops-tools <comando>
```

- `CLOUDOPS_NO_BANNER=1` tiene prioridad sobre la configuración en esa ejecución.

## Importante (precedencia)

Por ahora los comandos de escaneo (`init`, etc.) **no** leen automáticamente estos valores.
Todavía tienes que pasar las opciones manualmente cuando corres el comando:

```bash
cloudops-tools init --export-format json
```

## Validación

El comando `set` revisa que los valores tengan sentido y te avisa si algo está mal:

```bash
cloudops-tools config set skipGlobal tal vez
# Error: Valor inválido para skipGlobal: "tal vez". Se esperaba true o false.
```

```bash
cloudops-tools config set defaultFormat yaml
# Error: Valor inválido para defaultFormat: "yaml". Opciones válidas: csv, xlsx, json, both, all.
```
