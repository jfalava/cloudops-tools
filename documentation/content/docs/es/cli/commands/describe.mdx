# describir

Obtenga información detallada sobre un recurso de AWS específico, con formato Markdown.

## Uso

```bash
cloudops-tools describe <type> <region> <id> [options]
```

## Argumentos

| Argumento | Descripción                                                  | Requerido |
| --------- | ------------------------------------------------------------ | --------- |
| `type`    | Tipo de recurso (por ejemplo, `ec2`, `rds`, `lambda`, `vpc`) | Sí        |
| `region`  | Región de AWS donde existe el recurso                        | Sí        |
| `id`      | Identificador de recurso (ID de instancia, ARN, etc.)        | Sí        |

## Opciones

| Opción       | Descripción                                                                 | Predeterminado |
| ------------ | --------------------------------------------------------------------------- | -------------- |
| `--debug`    | Mostrar salida de error sin formato con seguimientos de pila                | `false`        |
| `--no-cache` | Deshabilite el almacenamiento en caché, obtenga siempre datos nuevos de AWS | `false`        |

## Tipos de recursos comunes

| Tipo       | Descripción                      | Formato de identificación                   |
| ---------- | -------------------------------- | ------------------------------------------- |
| `ec2`      | Instancias EC2                   | `i-xxxxxxxxxxxxxxxxx`                       |
| `rds`      | Instancias de bases de datos RDS | Identificador de instancia de base de datos |
| `lambda`   | Funciones lambda                 | Nombre de función o ARN                     |
| `vpc`      | Redes VPC                        | `vpc-xxxxxxxxxxxxxxxxx`                     |
| `dynamodb` | Tablas de DynamoDB               | Nombre de la tabla                          |

El comando `describe` admite tipos de recursos adicionales más allá de esta lista rápida (por ejemplo, S3,
CloudFront, Route53, IAM, KMS, Secrets Manager y más).

## Ejemplos

```bash
# Describe an EC2 instance
cloudops-tools describe ec2 us-east-1 i-1234567890abcdef0

# Describe an RDS database
cloudops-tools describe rds eu-west-1 my-database

# Describe a Lambda function
cloudops-tools describe lambda us-west-2 my-function

# Describe a VPC
cloudops-tools describe vpc us-east-1 vpc-0123456789abcdef0

# Describe a DynamoDB table
cloudops-tools describe dynamodb eu-central-1 my-table

# With debug output
cloudops-tools describe ec2 us-east-1 i-1234567890abcdef0 --debug
```

## Salida

El comando genera información detallada de recursos en formato Markdown, que incluye:

- Metadatos de recursos (ID, ARN, fecha de creación)
- Detalles de configuración
- Etiquetas
- Recursos asociados
- Configuración de seguridad
- Configuración de red

## Describir por lotes con la bandera --describe

También puede describir todos los recursos de un tipo en una región usando el indicador `--describe` del comando principal:

El lote `--describe` actualmente admite: `rds`, `ec2`, `lambda`, `vpc`, `dynamodb`.

```bash
# Describe all RDS instances in eu-south-2
cloudops-tools --describe rds --region eu-south-2

# Describe all EC2 instances
cloudops-tools --describe ec2 --region us-east-1

# Describe all Lambda functions
cloudops-tools --describe lambda --region eu-west-1

# Describe all VPCs
cloudops-tools --describe vpc --region ap-southeast-1

# Describe all DynamoDB tables
cloudops-tools --describe dynamodb --region us-west-2
```

Esto escribe un archivo Markdown en `inventory-output/{account-id}/describe-{type}-{region}-{timestamp}.md`

## Almacenamiento en caché

Las operaciones por lotes `--describe` se almacenan automáticamente en caché durante 5 minutos. Las llamadas de descripción repetidas dentro de esta ventana devuelven resultados almacenados en caché al instante:

```bash
# First call - fetches from AWS (5+ seconds)
cloudops-tools --describe ec2 --region us-east-1

# Second call within 5 minutes - returns cached data (instant)
cloudops-tools --describe ec2 --region us-east-1

# Bypass cache to get fresh data
cloudops-tools --describe ec2 --region us-east-1 --no-cache
```

El caché se almacena en `~/.config/cloudops-tools/inventory.db`
