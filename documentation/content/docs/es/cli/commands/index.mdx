# Descripción general de los comandos

Esta página es la referencia de comandos para las herramientas de CloudOps.

## Punto de entrada

`cloudops-tools` es el punto de entrada de la CLI.

- Sin argumentos, `cloudops-tools` imprime la ayuda y sale
- Ejecute análisis de inventario pasando las opciones de análisis del comando raíz (por ejemplo `--region`)
- Utilice subcomandos para flujos de trabajo avanzados

```bash
cloudops-tools [options]
```

## Subcomandos

| Comando                                      | Descripción                                                                  |
| -------------------------------------------- | ---------------------------------------------------------------------------- |
| [`init`](/es/docs/cli/commands/init)         | Genere escaneo de inventario entre regiones con opciones avanzadas           |
| [`describe`](/es/docs/cli/commands/describe) | Describir en profundidad un recurso de AWS específico                        |
| [`query`](/es/docs/cli/commands/query)       | Consultar datos históricos de inventario desde la base de datos SQLite local |
| [`config`](/es/docs/cli/commands/config)     | Administrar configuración persistente                                        |

## Banderas globales del marco

Estos son proporcionados por `@effect/cli` y aparecen en la salida de ayuda:

| Opción          | Descripción                                                                                    |
| --------------- | ---------------------------------------------------------------------------------------------- |
| `--help`, `-h`  | Mostrar ayuda del comando                                                                      |
| `--version`     | Mostrar versión de la aplicación                                                               |
| `--wizard`      | Iniciar el modo asistente para la entrada de comandos                                          |
| `--completions` | Generar script de finalización de shell (`sh`, `bash`, `fish`, `zsh`)                          |
| `--log-level`   | Establecer el umbral de registro de tiempo de ejecución (`all`, `trace`, `debug`, `info`, ...) |

## Ejemplos rápidos

```bash
# Show help
cloudops-tools --help

# Show examples
cloudops-tools --help-examples

# Show version
cloudops-tools --version

# Basic inventory for us-east-1
cloudops-tools --region us-east-1

# Inventory for multiple regions
cloudops-tools --region us-east-1,eu-west-1

# Scan specific services only
cloudops-tools --services EC2,RDS,S3 --region us-east-1

# Export to Excel format
cloudops-tools --export-format xlsx

# Describe all RDS instances in a region
cloudops-tools --describe rds --region eu-south-2

# Use `letme` with MFA profile from --account
cloudops-tools --use-letme --account engineering-prod --region us-east-1
```

## Notas de comportamiento

- Ejecutar `cloudops-tools` sin argumentos imprime la ayuda y sale (no inicia un análisis).
- `--help-examples` imprime ejemplos seleccionados y salidas.
- `--version` imprime la versión CLI instalada y sale.
- `--wizard` es proporcionado por `@effect/cli`; ayuda con la entrada de comandos pero no pasa por alto AWS
  requisitos de credencial.
