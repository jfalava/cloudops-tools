# Modelo de error

Las operaciones y servicios del SDK son valores `Effect`, por lo que los errores son valores que puede clasificar y manejar.

## Tipos de errores exportados

| Tipo de error | Fuente típica | Notas |
| ----------------- | --------------------------------- | ---------------------------------------------------------------------------------- |
| `AwsError` | Respuestas del servicio/SDK de AWS | Incluye `service`, `region`, `code`, `statusCode` y ayudantes como `isRetryable` |
| `CredentialError` | Errores de carga/autenticación de credenciales | Generalmente se recupera arreglando el entorno/perfil de autenticación |
| `ValidationError` | Entradas/opciones no válidas | La persona que llama debe corregir los datos antes de volver a intentarlo |
| `FileSystemError` | Operaciones de lectura/escritura/eliminación de archivos | Común en flujos de trabajo de informes/salida |

## Escenarios de falla comunes

| Escenario | Señal típica | Manejo recomendado |
| -------------------------------------- | ------------------------------------------------- | ----------------------------------------- |
| Problema de limitación de API/servicio transitorio | `AwsError` con código/estado reintentable | Reintentar con intentos de retroceso y límite |
| Credenciales no válidas/caducadas | `CredentialError` o `AwsError.isCredentialError` | Actualizar perfil/sesión y volver a intentarlo |
| Valores de región/servicio/filtro no válidos | `ValidationError` | Falla rápido y muestra un mensaje procesable |
| Fallo de escritura de salida | `FileSystemError` | Registrar la ruta de destino y detener el paso de salida |

## Patrón de reintento para errores de AWS

```ts
import { Duration, Effect, Schedule } from "effect";
import { AwsError, ComputeService, SDKLive } from "@cloudops-tools/sdk";

const program = Effect.gen(function* (_) {
  const compute = yield* _(ComputeService);
  return yield* _(compute.describeEC2("us-east-1"));
}).pipe(
  Effect.retry(
    Schedule.exponential(Duration.millis(250)).pipe(
      Schedule.intersect(Schedule.recurs(4)),
      Schedule.whileInput((error) => error instanceof AwsError && error.isRetryable),
    ),
  ),
);

await Effect.runPromise(program.pipe(Effect.provide(SDKLive)));
```

## Coincidir etiquetas de error específicas

```ts
import { Effect } from "effect";
import { CredentialError, UtilService, SDKLive } from "@cloudops-tools/sdk";

const accountIdProgram = Effect.gen(function* (_) {
  const util = yield* _(UtilService);
  return yield* _(util.getAccountId());
}).pipe(
  Effect.catchTag("CredentialError", (error: CredentialError) =>
    Effect.fail(new Error(`Credentials issue: ${error.message}`)),
  ),
);

await Effect.runPromise(accountIdProgram.pipe(Effect.provide(SDKLive)));
```
