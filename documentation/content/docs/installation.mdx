# Installation

## Prerequisites

- Node.js 18+ and npm
- AWS credentials configured (`~/.aws/credentials` or environment variables)

## Install via npm

```bash
npm install -g @cloudops-tools/cli
```

## Verify Installation

```bash
cloudops-tools --version
```

## How Installation Works

The npm package installs a small launcher and downloads a native binary for your platform from
GitHub Releases during `postinstall`.

Supported prebuilt platforms:

- Linux x64
- Windows x64
- macOS arm64

If you are on an unsupported platform, build from source instead:

- [Build CLI Binary](/docs/build-cli)

## AWS Credentials

CloudOps Tools uses standard AWS credential resolution:

1. Environment variables (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`)
2. Shared credentials file (`~/.aws/credentials`)
3. IAM roles for EC2/ECS/Lambda

```bash
# Set environment variables
export AWS_ACCESS_KEY_ID=your-access-key
export AWS_SECRET_ACCESS_KEY=your-secret-key
export AWS_REGION=us-east-1
```
