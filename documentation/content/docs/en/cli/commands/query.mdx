# query

Query historical inventory data stored in the local SQLite database without re-scanning AWS.

## Usage

```bash
cloudops-tools query [options]
```

## Description

The `query` command lets you analyze past inventory runs stored locally at `~/.config/cloudops-tools/inventory.db`. This enables trend analysis, change detection, and historical reporting without making AWS API calls.

## Options

| Option           | Alias | Description                                      | Default     |
| ---------------- | ----- | ------------------------------------------------ | ----------- |
| `--account`      | `-a`  | AWS account to query                             | `default`   |
| `--type`         | `-t`  | Filter by resource type (e.g., EC2, RDS, Lambda) | All types   |
| `--region`       | `-r`  | Filter by AWS region                             | All regions |
| `--days`         | `-d`  | Query resources from the last N days             | All time    |
| `--from`         |       | Query from date (ISO format: YYYY-MM-DD)         | -           |
| `--to`           |       | Query to date (ISO format: YYYY-MM-DD)           | -           |
| `--limit`        | `-l`  | Limit number of runs to display                  | `10`        |
| `--runs`         |       | List all inventory runs                          | `false`     |
| `--changes`      | `-c`  | Show changes since last run                      | `false`     |
| `--changes-days` |       | Days to compare for changes                      | `7`         |

## Subcommands

### List Runs

List all past inventory runs:

```bash
cloudops-tools query --runs
```

Output shows run ID, timestamp, mode, and resource count.

### Query Resources

Query historical resources with filters:

```bash
# All EC2 instances from last 7 days
cloudops-tools query --type EC2 --days 7

# All resources in us-east-1
cloudops-tools query --region us-east-1

# RDS instances from specific date range
cloudops-tools query --type RDS --from 2024-01-01 --to 2024-01-31

# Limit to 5 most recent runs
cloudops-tools query --limit 5
```

### Detect Changes

Compare the two most recent runs to detect infrastructure changes:

```bash
# Show changes from last 7 days
cloudops-tools query --changes

# Compare runs from last 30 days
cloudops-tools query --changes --changes-days 30
```

Change types displayed:

- **Added**: New resources not in previous run
- **Removed**: Resources deleted since previous run
- **Modified**: Resources with changed state (e.g., instance stopped)

## Examples

```bash
# List last 20 inventory runs
cloudops-tools query --runs --limit 20

# Find all Lambda functions from last 30 days
cloudops-tools query --type Lambda --days 30

# Check what changed in production account
cloudops-tools query --account 123456789012 --changes

# Query specific region and date range
cloudops-tools query --region eu-west-1 --from 2024-01-01 --to 2024-01-15

# Find all RDS and EC2 resources
cloudops-tools query --type RDS
cloudops-tools query --type EC2
```

## Notes

- The SQLite database is automatically populated when running `cloudops-tools init` or a root
  command scan
  with scan options (for example `cloudops-tools --region us-east-1`)
- Database location: `~/.config/cloudops-tools/inventory.db`
- Query operations are instant and don't require AWS credentials
- Changes are detected by comparing the two most recent runs within the specified time window

### Account Parameter

**Important:** The `--account` flag defaults to `default`. You must specify the same account ID used during `init` to query your data:

```bash
# First, run init (uses auto-detected account ID)
cloudops-tools init --region eu-central-1
# Account ID: 123456789012

# Query requires the same account ID
cloudops-tools query --runs --account 123456789012

# Without --account, defaults to "default" (no data found)
cloudops-tools query --runs
# Output: No inventory runs found
```

To find your account ID:

```bash
# Check what accounts have data
sqlite3 ~/.config/cloudops-tools/inventory.db "SELECT DISTINCT account_id FROM inventory_runs;"
```
