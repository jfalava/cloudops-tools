# Getting Started

Use this guide to install CloudOps Tools and run your first scan in a few minutes.

## What You'll Do

CloudOps Tools helps you:

- Inventory AWS resources across regions and services
- Export reports in CSV, Excel, or JSON
- Describe resources in detail
- Run security-focused scans

## 1. Install

<Tabs items={["npm", "pnpm", "Yarn", "Bun"]}>

```bash

```

  </Tab>

  <Tab value="Yarn">

Alternative for Yarn Classic (`1.x`):

```bash
yarn global add @cloudops-tools/cli
```

## 2. Verify Installation

```bash
cloudops-tools --version
```

If you run `cloudops-tools` with no arguments, the CLI prints help and exits.

## 3. Run Your First Scan

```bash
cloudops-tools --region us-east-1
```

The root command runs a quick scan when you provide scan options (for example `--region` or
`--services`).

## 4. Try a Security Audit

```bash
cloudops-tools init --mode security --export-format xlsx
```

## 5. Need More Examples?

```bash
cloudops-tools --help-examples
```

## 6. Query Historical Data

After running scans, query past inventories without AWS API calls. All data is stored in a local SQLite database (`~/.config/cloudops-tools/inventory.db`):

```bash
# Find your account ID from scans
sqlite3 ~/.config/cloudops-tools/inventory.db "SELECT DISTINCT account_id FROM inventory_runs;"

# List past inventory runs (use your account ID)
cloudops-tools query --runs --account YOUR_ACCOUNT_ID

# Detect infrastructure changes
cloudops-tools query --changes --account YOUR_ACCOUNT_ID

# Query specific resource types
cloudops-tools query --type EC2 --days 7 --account YOUR_ACCOUNT_ID
```
