# Utilities

SDK utility helpers live under `@cloudops-tools/sdk/lib`.

## Progress Events

`progressEmitter` emits lifecycle events during inventory runs.

Event families include:

- `started`
- `service_started`
- `service_completed`
- `service_failed`
- `progress`
- `file_written`
- `completed`
- `failed`

```ts
import { progressEmitter, type InventoryProgressEvent } from "@cloudops-tools/sdk";

progressEmitter.onProgress((event: InventoryProgressEvent) => {
  if (event.type === "progress") {
    console.log(`${event.percentage}% - ${event.message}`);
  }
});
```

## Inventory Database

`InventoryDbService` provides SQLite-based historical inventory storage. Data is stored at `~/.config/cloudops-tools/inventory.db`.

```ts
import { Effect } from "effect";
import { InventoryDbService, InventoryDbServiceLive } from "@cloudops-tools/sdk";

const program = Effect.gen(function* () {
  const db = yield* InventoryDbService;
  yield* db.initialize();

  // Save an inventory run
  const runId = yield* db.saveRun("123456789012", "basic", [
    { type: "EC2", name: "instance-1", region: "us-east-1", arn: "arn:aws:ec2:..." },
  ]);

  // Query past runs
  const runs = yield* db.getRuns("123456789012", 30);

  // Get resources from a specific run
  const resources = yield* db.getResources(runId, { type: "EC2" });

  // Detect changes between runs
  const changes = yield* db.getChanges("123456789012", 7);
});

await Effect.runPromise(program.pipe(Effect.provide(InventoryDbServiceLive)));
```

### InventoryDbService Methods

| Method           | Purpose                                          |
| ---------------- | ------------------------------------------------ |
| `initialize`     | Create database schema if needed                 |
| `saveRun`        | Store inventory run with all resources           |
| `getRuns`        | List past runs for an account                    |
| `getResources`   | Get resources from a specific run (with filters) |
| `queryResources` | Query resources across runs with filters         |
| `getChanges`     | Compare two most recent runs for changes         |
| `close`          | Close database connection                        |

## Output Helpers

| Helper                   | Purpose                       |
| ------------------------ | ----------------------------- |
| `writeInventoryFile`     | Write inventory as CSV/XLSX   |
| `csvToXlsx`              | Convert existing CSV to XLSX  |
| `createWebInventoryJson` | Build web-friendly JSON shape |
| `writeJsonInventoryFile` | Write JSON inventory output   |

## Configuration Helpers

| Helper                  | Purpose                                   |
| ----------------------- | ----------------------------------------- |
| `ConfigService`         | Load/save persisted CloudOps config       |
| `getConfigWithDefaults` | Merge defaults with runtime option values |
