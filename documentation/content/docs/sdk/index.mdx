# SDK Overview

The CloudOps Tools SDK (`@cloudops-tools/sdk`) is the programmatic foundation used by the CLI.

## SDK Package Entry Points

| Import path                       | Use for                                         |
| --------------------------------- | ----------------------------------------------- |
| `@cloudops-tools/sdk`             | Main exports for most integrations              |
| `@cloudops-tools/sdk/operations`  | Inventory orchestration                         |
| `@cloudops-tools/sdk/services`    | Service-level AWS inventory APIs                |
| `@cloudops-tools/sdk/lib`         | Helpers: config, events, output, version checks |
| `@cloudops-tools/sdk/types`       | Shared type definitions                         |
| `@cloudops-tools/sdk/credentials` | Credential provider helper                      |
