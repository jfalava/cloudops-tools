# Operations

Operations provide high-level workflows that compose many services.

## Inventory Generation

`generateInitInventoryEffect` runs cross-region inventory generation with support for:

- Modes: `basic`, `detailed`, `security`, `cost`
- Output formats: `csv`, `xlsx`, `json`, `both`, `all`
- Region limiting and global-service toggles
- Service filtering
- Progress event emission
- Automatic SQLite storage for historical queries
- Incremental scanning to output only changed resources

```ts
import { Effect } from "effect";
import { SdkLive, generateInitInventoryEffect } from "@cloudops-tools/sdk";

await Effect.runPromise(
  generateInitInventoryEffect(
    "123456789012",
    "security",
    "all",
    ["us-east-1", "eu-west-1"],
    false,
    {
      skipGlobal: false,
      onlyGlobal: false,
      services: ["EC2", "RDS", "S3"],
    },
  ).pipe(Effect.provide(SdkLive)),
);
```

### Incremental Scanning

Enable incremental mode to only output resources that have changed since the last scan:

```ts
import { Effect } from "effect";
import { SdkLive, generateInitInventoryEffect } from "@cloudops-tools/sdk";

await Effect.runPromise(
  generateInitInventoryEffect("123456789012", "basic", "csv", ["us-east-1"], false, {
    incremental: true, // Only output new/changed resources
  }).pipe(Effect.provide(SdkLive)),
);
```

Incremental mode uses resource fingerprints stored in SQLite to detect changes. The completion event includes statistics about new, changed, unchanged, and removed resources.

## Query Operations

Query historical inventory data from the local SQLite database without re-scanning AWS.

### Query Resources

`queryInventoryEffect` retrieves resources from past inventory runs:

```ts
import { Effect } from "effect";
import { SdkLive, queryInventoryEffect } from "@cloudops-tools/sdk";

const results = await Effect.runPromise(
  queryInventoryEffect("123456789012", {
    type: "EC2", // Filter by resource type
    region: "us-east-1", // Filter by region
    days: 7, // Last 7 days
  }).pipe(Effect.provide(SdkLive)),
);

// results: Array<{ runAt: string; resources: ResourceRecord[] }>
```

### List Inventory Runs

`listInventoryRunsEffect` shows past inventory executions:

```ts
import { Effect } from "effect";
import { SdkLive, listInventoryRunsEffect } from "@cloudops-tools/sdk";

const runs = await Effect.runPromise(
  listInventoryRunsEffect("123456789012", 30).pipe(Effect.provide(SdkLive)),
);

// runs: Array<{ id, accountId, timestamp, runAt, mode, totalResources }>
```

### Detect Changes

`getInventoryChangesEffect` compares the two most recent runs:

```ts
import { Effect } from "effect";
import { SdkLive, getInventoryChangesEffect } from "@cloudops-tools/sdk";

const changes = await Effect.runPromise(
  getInventoryChangesEffect("123456789012", 7).pipe(Effect.provide(SdkLive)),
);

// changes: Array<{ type, name, region, change, oldValue, newValue }>
// change: "added" | "removed" | "modified"
```

## When To Use Operations vs Services

- Use `operations` when you want SDK-managed orchestration and output handling.
- Use `services` when you want custom orchestration or targeted data collection.
- Use `query operations` to analyze historical data without AWS API calls.
